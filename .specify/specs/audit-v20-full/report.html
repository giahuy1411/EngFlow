Đo lại thì không phải lỗi

  • N+1 “tiềm ẩn”: hai repository được nghi ngờ đều map sang DTO chỉ dùng trường vô hướng, phạm vi hẹp → không có N+1. Không thêm tối ưu khi chưa đo.
  • /api/health trả 401: đúng thiết kế — đường này nằm sau lớp xác thực.
  • 4 dòng “Internal server error”: thuộc lượt khởi động trước, do client ngắt kết nối khi đang stream media. Lượt hiện tại 0 lỗi.
  • WebConfig.java: bị công cụ gắn cờ nhưng cả lớp bị comment-out có chủ đích (CORS trùng).

Tự đính chính về công cụ

  • Bộ lọc đầu tiên không hiểu text block của Java (""") nên báo sai “2 file đổi code”. Bản đúng: 139/139 comment-only.
  • Một checker khác báo “85/115 sai” — thực ra cẩm nang dùng đoạn code lược trích nên so khớp chuỗi tuyệt đối thất bại. Kiểm tay xác nhận remap đúng.

Ghi lại để báo cáo trung thực: công cụ sai từng tạo ra kết luận sai.
